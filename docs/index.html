İnsanlar

        
Hayvan sahipleri ve klinik personeli. Üç yaş grubu, sekiz ten tonu, başörtüsü seçeneği. Personelde önlük ya da forma, stetoskop ve yaka kartı var.

      

      
    

    

  






  

    
Kullanım

    
Tek dosyalık birleştirici ve iki JSON kütüphanesi. Çıktı düz bir SVG metni; web'de img etiketine, React Native'de SvgXml'e verilir.

    

      

        
Kurulum

        
Şimdilik doğrudan repodan alınıyor.


# repoyu indir
git clone https://github.com/kKerem/pofuduk

# JSON'u yeniden üret (isteğe bağlı)
node scripts/build.mjs

      

      

        
Çizim

        
Seed olarak kalıcı bir kimlik verin, isim değişse de avatar değişmez.


import pets from 'pofuduk/dist/pet-avatars.json'
import humans from 'pofuduk/dist/human-avatars.json'
import { renderPetAvatar, renderHumanAvatar } from 'pofuduk/src/render'

renderPetAvatar(pet.id, 'cat', pets)
renderHumanAvatar(owner.id, { gender: 'female' }, humans)
renderHumanAvatar(user.id, { role: 'staff' }, humans)

      

      

        
Seçimi saklamak

        
Önce seç, istersen bir parçayı elle değiştir, sonra çiz. Örneğin ameliyattan çıkan hastaya konik yaka.


const choice = selectPetAvatar(pet.id, 'dog', pets)
choice.parts.accessory = 'acc-cone'
const svg = composePetAvatar(choice, pets)

      

      

        
Ekrana basmak

        
Web'de data URL, React Native'de react-native-svg yeterli. Parçalarda filter, mask ya da degrade yok.


// web
<img src={`data:image/svg+xml;utf8,${encodeURIComponent(svg)}`} />

// React Native
<SvgXml xml={svg} width={40} height={40} />

      

    

  






  

    
Nasıl çalışır?

    
Avatarlar hazır resim değil. Her biri aynı 256×256 tuvalde çizilmiş parçaların üst üste takılmasıyla oluşur.

    

      
Seed'den seçim
Seed bir sayıya çevrilir, o sayı da sabit bir rastgele dizi başlatır. Kafa, kulak, desen, göz ve renk bu diziden sırayla seçilir.

      
Renk yer tutucuları
Parçalar renk taşımaz; {{fur}}, {{skin}}, {{hair}} gibi yer tutucular paletten doldurulur. Koyu tüylü hayvanlarda göz akı olan gözler seçilir.

      
Kil hissi
Her şekil üç tondan oluşur: koyu gövde, biraz kaymış ana renk ve açık bir parlama. Degrade ya da filtre yok, küçük boyutta da net kalır.
